# 执行环境记录

每个本地或集群执行环境使用一个独立文件，文件名与稳定 Site ID 一致：

- `local.md`：本地开发、单元测试和模拟集成测试。
- `kw_tz.md`：泰州，Slurm，第一阶段目标运行站点。
- `kw_bj.md`：北京，调度器和部署信息仍需进一步确认。

新会话执行命令前先读 `AGENT.md`，再读目标 site 文件。site 文件记录已核实的连接方式、工具、调度器、项目路径、数据入口和安全边界；不得依赖 `.bashrc`、alias、默认 PATH 或环境名称推断版本。

新增环境时复制现有文件的字段结构。未知字段保留 `TBD`，不要猜测。密码、私钥、token、Webhook 和带凭据 URL 永不写入记录。

远程操作的一般顺序：只读核验 → 专用目录 dry-run → 明确批准后的单任务真实投递。连接远程站点、同步代码、写入远程目录或提交调度任务前需要用户明确授权。
